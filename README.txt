NEON CYBER PLATFORMER — 10 LEVEL + FINAL BOSS EDITION

UPGRADES
- Ten distinct platform layouts.
- Difficulty increases through more hazards, faster hazards and moving drone enemies.
- Level 10 features a boss with a health bar and a shield/core phase. Jump onto the boss while its core is exposed to damage it. Three successful hits defeat it.
- A final victory screen appears after defeating the boss and collecting all Level 10 orbs.
- Start menu, instructions, pause/resume, restart, sound effects, particle effects and local personal-best score.

CONTROLS
A / D or Left / Right arrows: move
W / Up arrow / Space: jump
P or Escape: pause
Touch controls appear on compatible mobile devices.

NOTE
The personal-best score is saved in the browser on that device. It is not a shared online leaderboard.

UPDATE YOUR EXISTING GITHUB PAGES SITE
1. Extract this ZIP on your computer.
2. Open your GitHub repository: neon-cyber-platformer.
3. Click Add file > Upload files.
4. Upload these five files from the extracted folder: index.html, style.css, game.js, audio.js, particles.js.
5. If GitHub reports that files already exist, confirm replacing/overwriting them.
6. Scroll down, enter a commit message such as "Upgrade game with 10 levels and final boss", then click Commit changes.
7. Keep Settings > Pages set to Deploy from a branch, main, /(root).
8. Wait a few minutes. Open your game URL and press Ctrl+F5 to load the new files.
